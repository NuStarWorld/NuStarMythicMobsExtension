# 主配置：白名单与算式变量

## 用途

主配置用来开关调试输出、指定清空 AP 攻击属性时保留哪些属性，以及给算式中的数字起名字。它不代替 MM 的怪物文件或技能文件。

## 准备

1. 安装本扩展、`minecraft-next` 和对应版本的 MythicMobs。
2. 使用 AP 技能时安装 AttributePlus；使用 SX 技能时安装 SX-Attribute，不必为了威胁技能同时安装两者。
3. 首次启动后，备份 `plugins/NuStarMythicMobsExtension/config.yml` 再修改。
4. 要使用 `%...%` 变量，另行安装 PlaceholderAPI 和该占位符对应的扩展，确认输出只有数字。没有准备好时删除示例 `player_level` 项，先用纯数字。

## 配置项

| 参数 | 简写或其他写法 | 不填写时 | 填写说明与效果 |
| --- | --- | --- | --- |
| `debug` | 无 | `false` | 开启本扩展的调试输出；日常运行建议关闭，不是 MM 的调试开关。 |
| `white-attr-list` | 无 | 空列表；随包示例为“暴击几率”“暴击倍率” | [APMM](mechanics/apmm.md) / [FastAP](mechanics/fastap.md) 使用 `clear=true` 时保留的施法者 AP 属性。填写本服 AP 属性名，不是目标白名单；不控制 SX 属性。 |
| `variables` | 无 | 不提供自定义变量 | 左边是算式使用的名字，右边是数字、数字字符串或能输出数字的 PAPI 字符串。只在**玩家作为施法者**时加入算式；怪物施法时连这里的数字常量也不可用。 |

“不填写时”不等于首次生成文件的示例值。随包文件还带有 `factor: 1.68` 和 `player_level: '%player_level%'`，可按实际需求删除或修改。

### 变量填写方式

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `factor` | `1.68` | 数字常量。在公式中写 `factor`，不要写 `%factor%` 或 `<factor>`。 |
| `player_level` | `'%player_level%'` | PAPI 使用**施法玩家**的数据，不是目标的数据；需要对应扩展，结果必须是纯数字。 |
| MM `<P>` 一类写法 | 不能填在 `variables` 右边 | 这里不能填 `<caster.hp>`；要读取血量，在技能算式中改用 `caster_hp`。其他血量、等级名字见[内置变量](expressions.md)。 |

数字及数字字符串会缓存为常量；PAPI 结果不会作为永久常量缓存。不应依赖同一次技能中多次读取 PAPI 一定得到不同结果。变量名建议使用英文字母和下划线，且不要与五个内置变量重名：同名时内置值覆盖配置值。

## 完整可复制配置

下面是不要求 PAPI 的起步配置；它是主配置文件内容，不要放进 MM 的 `Skills` 文件。

```yaml
# plugins/NuStarMythicMobsExtension/config.yml
# 日常运行关闭调试信息。
debug: false
# 只有 AP 技能使用 clear=true 时才保留这些属性。
white-attr-list:
  - "暴击几率"
  - "暴击倍率"
# 配置变量只在玩家施法时可用；怪物技能直接写数字或用内置变量。
variables:
  factor: 1.68
  # 已安装 PAPI 与对应扩展并确认输出纯数字后，才取消下一行的注释。
  # player_level: '%player_level%'
```

玩家施法的算式可写 `factor*10`；怪物施法则写 `1.68*10`。完整的怪物技能挂接例子见[算式说明](expressions.md)。

### 修改后如何生效

- **修改主配置后，推荐重启服务器。** 这是本文建议的确定操作流程。
- `/nsme reload` 是扩展提供的配置重载入口；不能据此保证每次都从磁盘重新读文件，也不能保证已经加载的技能对象自动换用新配置。不要仅凭“已完成配置重载”就认定所有旧技能已更新。
- MM 怪物与技能 YAML 是另一套配置。只改 MM 文件时使用该版本的 MM 重载命令（通常为 `/mm reload`）；修改本扩展主配置并不等于重载 MM 技能。一次正常重启可以重新加载两边文件。

## 常见问题

- **变量明明写了，却提示找不到？** 检查施法者是不是玩家、名字是否拼对。怪物不能通过这份映射使用 `factor`，但仍可用 `caster_hp` 等内置变量。
- **输出“10级”“20%”也算数字吗？** 不算。PAPI 应输出 `10`、`20` 这样的纯数字。没有替换、带颜色、带单位或空文本都不能当作数值。
- **能在右边写 `1+2` 或 `<caster.hp>` 吗？** 不能。右边写数字，计算放到技能算式里；读取血量时在算式中写 `caster_hp`。
- **布尔值、列表可以当变量吗？** 不可以；也不要留空或写 `null`。变量用于数值计算，不支持这些值。
- **为什么没用到的 PAPI 项也报错？** 玩家上下文会读取整份配置变量表。删除不需要或未配置好的 PAPI 项；不要因为公式没写它，就认为不会读取它。
- **白名单为什么没效果？** 检查是否是 AP 技能、是否启用 `clear=true`，以及属性名是否与本服一致。它不会给玩家永久增加属性，也不是最终伤害倍率。
