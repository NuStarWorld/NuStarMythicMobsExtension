# 占位符

占位符是在执行时换成实际名字或数值的写法。本扩展目前注册了下面一个显示名称用的占位符。

| 写法 | 想显示的内容 | 当前状态 |
| --- | --- | --- |
| [`<nustar.threat.top>`](nustar-threat-top.md) | 本次事件触发者的威胁第一名名称 | **有卡服风险，暂不建议启用** |

这不是 PAPI 的 `%...%` 写法，也不是可以直接放进算式的数字。查询对象由本次事件决定，不会因为把消息发给另一个玩家就自动更换。

**先看风险提示，不要直接启用示例。** 当前有第一名记录时，某些调用方式可能让服务器卡住；不能简单加 `sync=true` 解决。示例已全部注释，仅保留为修复并验证后的写法参考。

按等级或血量计算技能数值，请看[计算公式与变量](../expressions.md)；配置 PAPI 数值请看[插件配置](../configuration.md)。
